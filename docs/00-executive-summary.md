# 00 · 总体方案摘要

> **一句话**：DeskBase 把「数据库」拆解成普通人每天真的会用的办公动作——记笔记、列清单、管名单、存截图——再把这堆东西稳稳地锁在用户自己的电脑里。

本文是整套方案的压缩版。想深入某一块，请按文末索引跳转。

---

## 一、产品定义

| 项 | 内容 |
|----|------|
| **名称** | DeskBase · 桌库 |
| **形态** | 原生桌面应用（Windows / Linux / macOS），可选手机远程端 |
| **性质** | 开源（Apache-2.0） |
| **定位** | 本地优先、隐私优先的办公工具箱 + 内置轻量 SQL 数据库 |
| **一句话价值** | 让不懂数据库的人，也能拥有一个「自己的数据仓库」 |
| **对标参照** | Notion 的易用性 × DB Browser 的数据力 × 密码管理器的隐私态度 |
| **明确不是** | 不是云端协作平台，不是 DBA 运维工具，不是通用数据库客户端 |

### 核心张力

这个产品同时追求两件通常互斥的事：

1. **极其简单**——打开就能用，不需要理解表、字段、主键。
2. **足够专业**——需要时能写 SQL、建索引、看执行计划、配触发器。

解法不是折中，而是**渐进式复杂度**：用同一份数据模型，提供两套操作路径。新手走「查询向导 + 表单」，高级用户走「SQL 编辑器 + 关系设计器」，两者操作的是同一张表，可以随时切换。

## 二、十条设计原则

| # | 原则 | 工程含义 |
|---|------|---------|
| 1 | **本地优先** | 数据默认只存在本机；断网时功能不缩水；联网是例外而非常态 |
| 2 | **渐进式复杂度** | 高级功能默认折叠，一级入口不超过 7 个可见项 |
| 3 | **零污染** | 便携版不写注册表、不装服务、不建计划任务、不改文件关联 |
| 4 | **默认最克制** | 所有开关默认指向「更少权限、更少联网、更少驻留」 |
| 5 | **不丢数据** | 崩溃/断电后必进恢复向导；编辑内容有草稿与版本 |
| 6 | **备份必须可验证** | 未做恢复演练的备份不算备份 |
| 7 | **AI 不出网** | 默认本地推理；数据外流必须逐次显式授权 |
| 8 | **可审计** | 依赖锁定 + SBOM + 可复现构建 + 权限清单公开 |
| 9 | **可迁移** | 全部数据可导出为开放格式，无供应商锁定 |
| 10 | **安静** | 空闲不烧 CPU、不轮询、不常驻多余进程 |

## 三、功能分区（十个一级模块）

```
① 工作台        首页 · 最近项目 · 待办聚合 · 日程 · 全局搜索 · 快捷操作
② 办公工具      笔记 · 文档 · 表格 · 看板 · 日历 · 待办 · 文件
                剪贴板历史 · 截图（含长截图）· OCR · 标签 · 模板 · 导入导出
③ 数据库        连接 · 表 · 视图 · 查询 · 关系 · 索引 · 导入导出
                备份 · 版本历史 · 权限 · 审计
④ 自动化        规则 · 触发器 · 定时任务 · 批量处理 · 工作流
⑤ AI 助手       本地模型 · 自然语言查询 · SQL 生成 · 摘要 · 分类
                翻译 · OCR · 语音转写 · 智能搜索 · 报表解读
⑥ 远程访问      设备配对 · 局域网直连 · 自托管中继 · 权限 · 审计
⑦ 备份与恢复    自动/手动备份 · 快照 · 版本历史 · 断电恢复
                恢复向导 · 健康检查 · 恢复演练
⑧ 设置          基础 · 外观 · 编辑器 · 快捷键 · 数据库 · 备份与恢复
                隐私与安全 · AI · 远程访问 · 插件 · 高级 · 关于
⑨ 帮助与教程    新手引导 · 场景教程 · 快捷键速查 · SQL 教程
                备份恢复教程 · 远程连接教程 · 隐私说明
⑩ 插件          插件市场 / 本地插件 · 权限 · 更新 · 卸载
```

**分区铁律**（不允许被打破）：

- 截图永远在「办公工具」，不进数据库模块。
- 备份永远是一级模块，不藏在设置深处。
- AI 隐私开关在「AI 助手」和「设置 → 隐私与安全」**两处都能找到**，状态双向同步。
- 全局搜索、命令面板、最近使用属于横切能力，常驻可达，不归属任何单一模块。

完整三层结构见 [03 · 信息架构](03-information-architecture.md)。

## 四、数据架构总览

```
┌──────────────────────────────────────────────────────────────┐
│  表现层   桌面 UI（新手视图 / 高级视图）· 手机远程端          │
├──────────────────────────────────────────────────────────────┤
│  能力层   办公工具引擎 · 数据库引擎 · 备份引擎 · AI 引擎      │
│           自动化引擎 · 远程服务 · 插件宿主                    │
├──────────────────────────────────────────────────────────────┤
│  契约层   统一数据访问接口（受控、可审计、可鉴权）             │
├──────────────────────────────────────────────────────────────┤
│  存储层   主数据文件（WAL 事务）                             │
│           版本历史库 · 索引库 · 向量库 · 附件目录 · 缓存目录   │
├──────────────────────────────────────────────────────────────┤
│  安全层   密钥管理 · 加密（库级 / 字段级 / 备份级）· 审计日志  │
├──────────────────────────────────────────────────────────────┤
│  系统层   文件系统 · OS 密钥链 · 通知 · 剪贴板 · 屏幕捕获      │
└──────────────────────────────────────────────────────────────┘
```

### 关键存储约定

| 数据 | 位置 | 默认加密 | 说明 |
|------|------|---------|------|
| 用户主数据 | 数据目录 `data/main.*` | 可选（首启时询问） | WAL 模式，单文件便于携带 |
| 版本历史 | `data/history/` | 同主库 | 可设置保留窗口与容量上限 |
| 附件与截图 | `data/attachments/` | 可选 | 按内容哈希分片存放，天然去重 |
| 向量索引（AI） | `data/vectors/` | 同主库 | 可重建，可单独清除 |
| 缓存 | `cache/`（可随时删除） | 否 | 有容量上限，退出即释放 |
| 日志 | `logs/` | 否 | 自动轮转，默认保留 7 天 |
| 备份 | 用户指定目录 | **默认开** | 不默认放程序目录，不默认上云 |

> **可携带性**：整个数据目录复制走 = 完整迁移。这是设计上刻意保证的能力。

## 五、五条不可退让的工程底线

### 底线 1 · 不丢数据

- 事务 + WAL（或等价机制）+ 原子写入 + `fsync` + 定期 checkpoint
- 异常退出检测，下次启动**自动进入恢复向导**
- 文档 / 表格 / 记录级自动保存与草稿恢复
- 版本历史 + 回收站 + 误删恢复
- **验证手段**：写入过程中强杀进程 100 次的破坏性测试

### 底线 2 · 不泄露

- 网络**默认关闭**；联网行为全部记入审计日志
- 无遥测、无埋点、无崩溃上报、无第三方数据收集
- OCR / 截图 / AI 全部本地处理
- 远程通道强制端到端加密，中继不可读内容
- **验证手段**：抓包 + 完全断网功能测试

### 底线 3 · 不污染

- 便携版：解压即用，**零注册表写入**
- 安装版：只写卸载所必需的最小信息，卸载时彻底删除
- 不捆绑、不静默安装、不强制重启、不强制登录、不强制联网
- **验证手段**：干净虚拟机安装→使用→卸载，残留项必须为 **0**

### 底线 4 · 不锁定

- 全部数据可导出为 CSV / JSON / SQL 等开放格式
- 数据库文件为开放/标准格式，可用第三方工具打开
- 插件接口公开，不依赖私有服务
- **验证手段**：仅用第三方工具即可完整读出用户全部数据

### 底线 5 · 不喧闹

- 空闲 CPU 平均 ≤ 0.3%，无周期性轮询尖峰
- 无秒级轮询、无隐藏定时器、无后台驻留进程
- 退出即释放：无残留进程、服务、计划任务、驱动、系统钩子
- **验证手段**：空闲 30 分钟的资源曲线 + 退出后进程/句柄审计

## 六、关键量化目标（v1.0 验收线）

| 类别 | 指标 | 目标 |
|------|------|------|
| 体积 | Windows 安装包 | ≤ 80 MB |
| 体积 | 便携版解压后 | ≤ 220 MB |
| 启动 | 冷启动到可交互 | ≤ 1.2 s |
| 启动 | 热启动 | ≤ 400 ms |
| 内存 | 空闲占用 | ≤ 180 MB |
| CPU | 空闲平均 | ≤ 0.3% |
| 渲染 | 万行表格滚动 | ≥ 55 FPS |
| 查询 | 万行表索引命中 | ≤ 50 ms |
| 搜索 | 10 万条全文首屏 | ≤ 300 ms |
| 备份 | 1 GB 库增量备份 | ≤ 20 s |
| 同步 | 同网段局域网延迟 | ≤ 800 ms |
| 卸载 | 彻底清除模式残留项 | **0** |

完整指标、测试方法与达标判据见 [14 · 性能优化与量化指标](14-performance-budget.md)。

## 七、隐私与 AI 的边界设计

这是本项目最容易被做坏的地方，因此单独说明。

### 三级数据分类

| 级别 | 内容 | 默认处理 |
|------|------|---------|
| **S0 公开** | 界面文案、内置模板、内置词典 | 可随程序分发 |
| **S1 个人** | 笔记、待办、日历、文件路径 | 仅本地存储，可加密 |
| **S2 敏感** | 密码字段、身份证件、财务记录、截图、OCR 结果、AI 对话 | 本地存储 + 默认加密 + 永不外发 |

### AI 的四道闸门

1. **默认本地**：模型推理在本机完成，模型文件可离线下发。
2. **数据不出境**：S1/S2 数据不进入任何网络请求体。向量索引与对话记录同样本地化。
3. **外发需逐次授权**：若用户主动配置外部 AI 服务，每次调用需显式确认，并提供**脱敏预览**（显示实际将发送的内容）。
4. **可审计可关闭**：所有 AI 网络调用记入审计日志；一键完全关闭是最高优先级开关。

> 详见 [09 · 本地 AI 架构](09-local-ai.md)。

## 八、安装与卸载体验摘要

### 安装向导步骤

```
欢迎 → 许可协议 → 隐私说明 → 安装路径 → 数据目录 → 组件选择
     → 快捷方式 → 备份目录 → 远程访问选项 → 隐私选项
     → 摘要确认 → 安装进度 → 完成
```

- 支持**一键默认安装**（全部取最克制默认值）与自定义安装。
- 界面自绘：现代、极简、品牌一致，支持亮/暗模式、高 DPI、多语言、键盘操作、屏幕阅读器。
- 进度条**真实反映进度**，不假进度、不卡在 99%。
- 安装页显式展示隐私承诺：无遥测 · 无捆绑 · 无强制联网 · 数据默认本地 · 备份默认本地。

### 卸载两档

| 模式 | 行为 |
|------|------|
| **保留数据卸载** | 仅移除程序文件，保留数据目录、配置与备份 |
| **彻底清除卸载** | 二次确认 + 逐条列出删除清单，之后删除程序、缓存、日志、临时文件、数据库、配置、插件、服务、计划任务、快捷方式、防火墙规则、注册表项 |

卸载界面同样是自有品牌界面，不用系统默认卸载框。

> 详见 [12 · 安装与卸载体验](12-installer-and-uninstaller.md)。

## 十、技术选型立场

**本方案不绑定任何具体技术栈。** 我们的立场是：

| 层 | 选型原则 | 关键约束 |
|----|---------|---------|
| 桌面外壳 | 能提供原生体验、系统集成与低内存占用 | 冷启动 ≤ 1.2 s；空闲内存 ≤ 180 MB |
| 前端 | 组件化、可虚拟滚动、可主题化 | 主题能力需支持亮/暗与高 DPI |
| 数据库 | 单文件、支持事务与 WAL、可嵌入 | 必须支持崩溃一致性与字段级加密 |
| 本地 AI | 可插拔推理后端 | 必须支持完全离线；模型可替换 |
| 加密 | 成熟的 AEAD 套件 + 抗暴力 KDF | 密钥材料不落明文磁盘 |
| 打包 | 能产出零污染便携版与受控安装器 | 便携版不得写注册表 |

候选方案、优缺点与适用条件见 [17 · 技术选型建议](17-tech-selection.md)，
已固化的决策见 [adr/](adr/)。

## 十一、本方案刻意排除的东西

| 不做 | 原因 |
|------|------|
| 在线协作 / 多人实时协同 | 与「本地优先」定位冲突，需要中心化服务 |
| 云端账号体系 | 会引入强制登录与数据托管 |
| 遥测 / 行为分析 / 崩溃上报 | 与隐私承诺根本冲突 |
| 广告 / 推广位 / 联盟链接 | 会侵蚀产品判断力 |
| 通用数据库客户端（多方言） | 先做好本地这一件事，避免功能稀释 |
| 重量级 DBA 运维（集群、主从、压测） | 目标用户不需要 |
