# 03 · 信息架构与功能分区

> 用户永远不该问「那个功能到底在哪儿」。如果有这个问题，是我们的错，不是他的。

## 一、架构总则

### 1.1 三层结构

```
一级模块（全局导航栏，≤ 10 个）
   └── 二级功能（模块内标签 / 侧栏，≤ 7 个可见）
          └── 三级设置（功能内选项，默认折叠）
```

| 层 | 位置 | 可见性 | 数量约束 |
|----|------|-------|---------|
| 一级模块 | 全局侧边栏 | 常驻可见 | 固定 10 个，不再增加 |
| 二级功能 | 模块内顶部标签或左侧栏 | 常驻可见 | 默认 ≤ 7 个，超出折叠进「更多」 |
| 三级设置 | 功能内的齿轮 / 展开面板 | **默认折叠** | 不限，但需分类 |

### 1.2 归属铁律

一个功能只能属于一个一级模块。以下是**明令禁止的错位**：

| ❌ 禁止 | ✅ 正确归属 | 理由 |
|--------|-----------|------|
| 截屏功能放在「数据库」模块 | 办公工具 → 截图 | 截图与数据库无关，是通用办公能力 |
| 备份藏在「设置 → 高级」深处 | **备份与恢复一级模块** | 数据安全是产品核心承诺，必须最高可达性 |
| OCR 放在「AI 助手」 | 办公工具 → OCR（AI 仅作可选增强） | OCR 是基础办公能力，本地引擎即可完成，不该被 AI 开关绑架 |
| 快捷键设置散落在各功能页 | 设置 → 快捷键（统一入口） | 用户需要一处看全所有快捷键并检测冲突 |
| 标签管理分散在各模块 | 办公工具 → 标签（统一管理） | 标签是横切的，但管理入口需唯一 |
| 「数据库加密」只在 AI 隐私页出现 | 设置 → 隐私与安全 + 设置 → 数据库（两处可达） | 用户会在这两处找 |
| AI 隐私开关只在设置里 | AI 助手模块内 + 设置 → 隐私（双向同步） | 用户在 AI 界面时想立刻关掉它 |

### 1.3 横切能力（不归属任何模块，但处处可达）

以下能力不占一级模块位，但必须在任何位置可快速唤起，且**行为一致**：

| 横切能力 | 唤起方式 | 行为约定 |
|---------|---------|---------|
| 全局搜索 | `Ctrl/Cmd + K` 或 `Ctrl/Cmd + Shift + F` | 跨全部模块检索，结果分组显示，可直接跳转 |
| 命令面板 | `Ctrl/Cmd + K`（与搜索同一入口，前缀区分为命令） | 执行任意操作，无需找菜单 |
| 最近使用 | 工作台首页 + 各模块顶部 | 最多 10 项，可清除，可关闭 |
| 收藏 | 右键 / 星标按钮 | 跨模块统一收藏夹 |
| 通知中心 | 右上角铃铛 | 备份结果、任务完成、同步状态 |
| 上下文帮助 | `F1` 或右下角 `?` | 根据当前页面给出对应帮助，不跳外部文档 |
| 全局快捷键 | 用户自定义 | 冲突检测、方案导入导出 |
| 剪贴板历史 | 全局快捷键 | 属办公工具，但可全局唤起 |

### 1.4 导航辅助

- **面包屑**：任何三层以上深度必须显示完整路径，每级可点击返回。
- **面包屑示例**：`数据库 › 客户库 › 表：订单 › 索引`
- **前进/后退**：`Alt + ←` / `Alt + →`，记录导航历史。
- **快速切换**：`Ctrl + P` 打开「最近打开的库/表/笔记」列表。
- **新手模式**：一级模块可见项缩减为 5 个（工作台、办公工具、数据库、备份与恢复、设置），其余折叠。

## 二、一级模块与二级功能全表

### ① 工作台 `Workbench`

> **一句话**：打开软件第一眼看到的地方，只说「你上次在做什么」和「你今天要做什么」。

| 二级功能 | 内容 | 优先级 |
|---------|------|-------|
| **首页** | 今日待办、最近项目、快捷操作、问候语（可关） | MVP |
| **最近项目** | 最近打开的笔记/表格/数据库/文件，可固定、可清除 | MVP |
| **待办聚合** | 跨库跨笔记汇总所有待办，按今天/本周/逾期分组 | MVP |
| **日程** | 今日日程 + 未来 7 天预览，与日历模块联动 | MVP |
| **快捷操作** | 新建笔记/表格/待办/截图/导入，可自定义常用动作 | MVP |
| **全局搜索** | 跨模块统一检索（横切能力的落地视图） | MVP |
| **仪表盘** | 数据概览：库数量、记录总数、备份状态、存储占用 | 进阶 |
| **自定义小组件** | 用户拖拽组合首页小组件 | 进阶 |

**三级设置**
- 首页显示哪些卡片（可勾选顺序）
- 是否显示问候语与姓名
- 启动时打开哪个页面（工作台 / 上次页面 / 指定库）
- 最近项目保留条数（默认 10）

- 是否自动 OCR（默认关闭，避免无谓算力消耗）
- 历史保留策略（数量上限 / 时间窗口 / 容量上限）
- 遮罩颜色与边框
- 多显示器行为

### ③ 数据库 `Database`

> **一句话**：真正的数据库能力都在这儿，但新手第一次进来看到的应该是「查询向导」，不是 SQL 编辑器。

| 二级功能 | 三级内容 | 优先级 |
|---------|---------|-------|
| **数据库连接** | 新建本地库、打开已有库、最近库、库属性、重命名、移动 | MVP |
| **表** | 建表向导、字段编辑、类型、约束、默认值、注释、重命名、复制结构、清空 | MVP |
| **视图** | 视图设计器（可视化/DDL 双模式）、物化视图 | 进阶 |
| **查询** | SQL 编辑器、执行、结果表格、多标签、历史、收藏、参数化 | MVP |
| **关系** | ER 图、外键设计、一对多/多对多、级联规则 | MVP |
| **索引** | 索引管理、建议、使用统计、重建/优化 | 进阶 |
| **触发器** | 触发器设计器、事件类型、条件、动作 | 进阶 |
| **数据编辑** | 数据网格编辑、批量更新、行内校验、撤销 | MVP |
| **导入** | CSV/JSON/Excel/SQL，字段映射、类型推断、预览、错误报告 | MVP |
| **导出** | CSV/JSON/Excel/SQL/Markdown，筛选导出、批量导出 | MVP |
| **查询向导** | 免 SQL 的图形化查询构建器（新手默认入口） | MVP |
| **自然语言查询** | 输入中文问题 → 生成 SQL（展示 SQL 供确认） | 进阶 |
| **备份** | 库级备份入口（跳转至备份与恢复模块的对应任务） | MVP |
| **版本历史** | 记录级与库级历史、diff、回滚 | 进阶 |
| **权限** | 本地角色、（启用远程时）远程用户权限 | 进阶 |
| **审计** | 数据变更审计、登录审计、导出审计 | 进阶 |
| **API 生成** | 把表暴露为本地 HTTP 接口（默认仅 127.0.0.1） | 插件 |
| **执行计划** | EXPLAIN 可视化、慢查询标记、索引建议 | 进阶 |

**三级设置（数据库）**
- 默认库存储位置
- 是否启用加密（首启询问，之后可在设置修改）
- 自动保存事务提交模式
- WAL checkpoint 间隔
- 查询超时（默认 30 秒，可设无限）
- 结果集最大行数（默认 10 000，超出分页）
- SQL 编辑器：字体、字号、Tab 宽度、自动补全开关、格式化风格、关键字大小写
- 是否记录 SQL 执行日志（默认关闭，隐私考虑）
- 索引自动建议（默认开启）

### ④ 自动化 `Automation`

> **一句话**：让软件替你重复做那些你每天都要做一次的事。

| 二级功能 | 三级内容 | 优先级 |
|---------|---------|-------|
| **规则** | IF 条件 THEN 动作、条件组合（与/或）、动作链 | 进阶 |
| **触发器** | 数据变更触发、时间触发、手动触发 | 进阶 |
| **定时任务** | Cron 风格或可视化周期、启用/暂停、执行历史、失败重试 | 进阶 |
| **批量处理** | 批量更新、批量导入、批量导出、批量重命名、批量打标签 | 进阶 |
| **工作流** | 多步骤编排、分支、变量、错误处理、调试 | 进阶 |

**三级设置（自动化）**
- 最大并发任务数（默认 1，避免资源争抢）
- 任务失败重试次数与退避策略
- 任务执行日志保留天数（默认 30 天）
- 是否允许任务在系统休眠时延后执行（默认：延后）
- 通知方式（应用内 / 系统通知 / 两者）
- 任务执行窗口（如"只在 22:00–06:00 执行备份"）

### ⑤ AI 助手 `AI`

> **一句话**：默认全部在本机跑。它替你读，替你整理，但不替你决定，更不把你的东西送出去。

| 二级功能 | 三级内容 | 优先级 |
|---------|---------|-------|
| **模型管理** | 本地模型下载/校验/切换/卸载、占用提示、推理后端选择 | 进阶 |
| **自然语言查询** | 中文问题 → SQL，展示生成的 SQL 供确认后再执行 | 进阶 |
| **数据摘要** | 对表/文档/选区生成摘要，可指定长度与风格 | 进阶 |
| **智能分类** | 自动打标签、自动归类、批量分类 | 进阶 |
| **翻译** | 选中文本翻译、整篇翻译、术语表 | 进阶 |
| **OCR（AI 增强）** | 手写体、复杂版式、表格结构还原（基础 OCR 在办公工具模块） | 进阶 |
| **语音转写** | 音频转文字、会议记录、时间轴 | 进阶 |
| **智能搜索** | 语义搜索、相似内容推荐 | 进阶 |
| **报表解读** | 对查询结果生成通俗解释与洞察 | 进阶 |
| **对话记录** | 本地历史、搜索、导出、一键清空 | 进阶 |
| **AI 隐私面板** | 模型来源、是否联网、数据流向、当前开关、最近调用记录 | MVP |

**三级设置（AI）**
- 默认推理后端（本地 / 外部服务）
- 本地模型路径与显存/内存上限
- 是否允许模型使用 GPU（默认：可用则用，可关）
- 单次推理超时
- 向量索引：构建策略、更新频率、存储上限、一键重建/清除
- 对话记录保留策略
- **外部 AI 服务**（默认完全关闭）：
  - 服务地址、认证方式（存于系统密钥链）
  - 每次调用是否需确认（**默认必须确认**）
  - 脱敏规则（用户名/手机号/邮箱/身份证号自动替换）
  - 允许发送的数据分类（默认只允许 S0；S1/S2 需单独逐类授权）
  - 调用审计日志
- **一键完全关闭 AI**（最高优先级开关，关闭后所有 AI 入口隐藏）

### ⑥ 远程访问 `Remote`

> **一句话**：把手机变成电脑的安全遥控器，中间不经过任何看得见你内容的人。

| 二级功能 | 三级内容 | 优先级 |
|---------|---------|-------|
| **服务开关** | 完全关闭（默认）/ 仅局域网 / 局域网 + 自托管中继 | 进阶 |
| **设备配对** | 二维码配对、一次性配对码、设备指纹、配对有效期 | 进阶 |
| **已配对设备** | 设备列表、最后活跃时间、权限查看、一键吊销 | 进阶 |
| **局域网直连** | 自动发现（mDNS/广播）、直连状态、端口可配 | 进阶 |
| **自托管中继** | 中继地址配置、连接测试、中继不可读声明 | 进阶 |
| **权限** | 按数据库/表/字段/操作/时段细分授权 | 进阶 |
| **审计** | 连接记录、操作记录、导出记录、异常告警 | 进阶 |
| **断开与吊销** | 一键断开全部、吊销所有授权、重置配对密钥 | MVP |

**三级设置（远程访问）**
- 监听端口（默认随机高位端口）
- 是否允许局域网外访问（**默认禁止**）
- 单设备最大并发连接
- 空闲断开时间（默认 5 分钟，省电）
- 是否允许远程修改数据（默认：只读）
- 是否允许远程导出（默认：禁止）
- 通知推送频率限制

### ⑦ 备份与恢复 `Backup & Restore`

> **一句话**：一级模块，不许藏在设置里。而且要能证明它真的能用。

| 二级功能 | 三级内容 | 优先级 |
|---------|---------|-------|
| **自动备份** | 开关（默认开）、频率、时间窗口、触发条件 | MVP |
| **手动备份** | 立即备份、备份时备注、选择性备份（只备份某些库） | MVP |
| **备份位置** | 本地目录、移动硬盘、NAS、自托管服务；**默认不上传第三方云** | MVP |
| **备份类型** | 全量、增量、差异 | 进阶 |
| **快照** | 手动/自动快照、命名、说明、锁定防删 | MVP |
| **版本历史** | 时间点浏览、diff 查看、任意时间点恢复 | 进阶 |
| **时间点恢复** | 选择时间点 → 预览 → 恢复到新库或覆盖当前库 | 进阶 |
| **断电与崩溃恢复** | 异常退出检测 → 恢复向导 → 恢复报告 | MVP |
| **恢复向导** | 从备份/快照/版本恢复，含沙箱预览 | MVP |
| **备份健康检查** | 校验文件完整性、加密可解密性、最近备份可用性 | 进阶 |
| **恢复演练** | 在沙箱中真实恢复一份并校验，输出演练报告 | 进阶 |
| **备份清理** | 保留策略（份数/时长/容量）、手动清理、锁定保护 | MVP |
| **导出与迁移** | 一键全量导出为开放格式目录 | MVP |

**三级设置（备份与恢复）**
- 自动备份频率（默认：每天一次）
- 自动备份时间窗口（默认：空闲时段，如 02:00–05:00，且仅在程序运行时触发）
- 保留份数（默认 30）与保留时长（默认 90 天）
- **备份加密**（默认：跟随主库加密状态；独立口令可选）
- 压缩级别（默认：标准）
- 是否生成校验和（**默认：是，不可关闭**）
- 备份完成后是否自动执行完整性验证（**默认：是**）
- 备份失败是否通知（**默认：是，且显著提示**）
- 同时保留几个备份目标（默认 1，最多 3；建议至少 1 个异地介质）
- 恢复演练频率（默认：每季度提醒一次）

### ⑧ 设置 `Settings`

> **一句话**：分类清晰、可搜索、每项有解释、有默认值、有影响范围、可导入导出、可单项重置。

| 二级分类 | 主要内容 | 优先级 |
|---------|---------|-------|
| **基础** | 语言、启动行为、数据目录、默认新建位置、自动更新检查（默认关） | MVP |
| **外观** | 主题（9 个 + 跟随系统）、质感强度、字体（预设/导入/三槽位）、排版、动效强度、辅助功能 | MVP |
| **编辑器** | Markdown/富文本默认模式、字体、行高、拼写检查、自动保存间隔、Tab 行为 | MVP |
| **快捷键** | 全局与应用内、冲突检测、方案导入导出、恢复默认、分场景配置 | MVP |
| **数据库** | 默认存储、加密、checkpoint 间隔、查询超时、结果集上限、SQL 编辑器偏好 | MVP |
| **备份与恢复** | 同「备份与恢复」模块的三级设置（此处提供集中视图） | MVP |
| **隐私与安全** | 网络总开关、遥测（固定关闭且不可开）、剪贴板策略、日志级别、审计日志、加密、密钥管理 | MVP |
| **AI** | 同「AI 助手」的三级设置（此处提供集中视图） | MVP |
| **远程访问** | 同「远程访问」的三级设置（此处提供集中视图） | 进阶 |
| **插件** | 已装插件、权限查看、启用/禁用、更新、卸载、插件市场入口 | 进阶 |
| **高级** | 实验性功能、日志详细程度、缓存管理、数据库完整性检查、重置单/全部设置 | 进阶 |
| **关于** | 版本、构建信息、许可证、第三方组件与许可证清单（SBOM）、隐私说明、致谢、检查更新（手动） | MVP |

**设置界面必备能力**
1. **搜索**：输入关键字即时过滤设置项（含别名，如搜「字体」能找到外观与编辑器两处）。
2. **每项说明**：每个设置项必须有 `?` 图标，点开显示：作用、默认值、取值范围、影响范围。
3. **影响范围标注**：标注该项影响哪些模块，以及是否涉及隐私 / 稳定性。
4. **重启提示**：需要重启才生效的项旁标注 `需重启`。
5. **导入导出**：整份设置可导出为 JSON，可导入；支持选择性导出（不含敏感项）。
6. **单项重置**：每项右侧有「恢复默认」。
7. **全部重置**：`高级 → 重置全部设置`，二次确认。
8. **高级折叠**：`高级` 分类默认折叠，展开时提示「可能影响稳定性或隐私」。

## 四、新手模式与高级模式

### 4.1 模式对比

| 维度 | 简洁模式（默认） | 高级模式 |
|------|----------------|---------|
| 一级模块可见 | 5 个：工作台 / 办公工具 / 数据库 / 备份与恢复 / 设置 | 全部 10 个 |
| 二级功能可见 | 核心 4–5 个，其余折叠「更多」 | 全部 |
| 新建题库入口 | 一键「新建表」，字段类型自动推荐 | 完整字段类型与约束 |
| 查询入口 | 查询向导 | SQL 编辑器（向导仍可用） |
| 时间/日期字段 | 直接选 | 可选时区、精度、格式 |
| 索引/触发器/视图 | 隐藏 | 可见 |
| 快捷键提示 | 只显示常用 | 全部 |
| 设置项 | 常用项展开，高级折叠 | 全部展开（仍标注警告） |
| 错误信息 | 通俗中文 + 「怎么办」 | 附错误码与技术细节 |

### 4.2 切换规则

- 切换入口：`设置 → 外观 → 界面模式`，或首次使用引导中询问。
- **切换不改变数据**，只改变界面呈现。新手模式下建的表，在高级模式下完全可见、可编辑。
- **升级路径不能有断层**：任何在新手模式建立的实体，都必须能在高级模式中被完整表达（不允许出现"新手建的字段在高级模式里改不了"的情况）。
- 切换到简洁模式时，若当前正在使用高级功能，给出提示但不强制退出。
- 各功能页可单独「展开更多」，此操作不改变全局模式。

### 4.3 折叠规范

任何折叠的高级内容必须：

1. 有明确的展开控件（不是隐藏的角落）。
2. 展开控件旁标注影响提示，如 `⚠ 可能影响稳定性或隐私`。
3. 首次展开时给出简短解释（一句话），可永久关闭。
4. 记住用户的展开状态，下次保持。

## 五、导航可达性规则

| 规则 | 要求 |
|------|------|
| 三次点击原则 | 任何核心功能从启动开始 ≤ 3 次点击可达 |
| 快捷键覆盖 | 所有高频操作必须有默认快捷键 |
| 搜索覆盖 | 所有设置项、所有数据库对象、所有笔记/表格，均可通过全局搜索找到 |
| 命令面板覆盖 | 所有菜单动作都可在命令面板中执行 |
| 返回一致性 | 任何层级都可用 `Esc` 返回上一级，`Alt+←` 返回上一页 |
| 空态引导 | 每个空列表必须有引导文案 + 一个明确的行动按钮（如「导入一份 CSV 试试」） |
| 无死路 | 任何界面都不允许出现「只能关闭窗口才能出去」的状态 |

## 六、信息架构反模式清单

以下是我们在评审中会直接打回的架构问题：

| 反模式 | 为什么不行 |
|-------|-----------|
| 把「备份」放进「设置 → 高级」 | 核心承诺必须最高可达，藏起来等于没有 |
| 一级模块超过 10 个 | 超出认知负荷，用户开始"记不住在哪儿" |
| 同一功能在两个模块各有一份实现 | 行为不一致，维护成本翻倍 |
| 把截图、录屏、OCR 拆到三个不同模块 | 用户的心智模型是"我在整理屏幕上的东西"，应聚在一起 |
| 用「更多」折叠掉一个高频功能 | 折叠只留给低频与高风险功能 |
| 状态开关在两处显示但不同步 | 用户会以为其中一个坏了 |
| 高级功能在新手模式下直接删除 | 会造成升级断层，用户需要重建数据 |
| 设置项没有默认值说明 | 用户改完不记得原来是什么，无法回退 |
| 空列表只显示"暂无数据" | 用户不知道下一步该做什么 |
| 报错只显示错误码 | 普通用户看不懂，等于没报错 |
