# 12 · 安装界面、安装流程、卸载界面与卸载流程详细设计

> 安装向导是用户与产品的**第一次面对面**。它不该是一次行政手续，而该是一次介绍。
>
> 本文聚焦**界面与体验设计**；注册表落点、零污染清单、技术实现细节见 [11 · 安全与资源优化专项](11-security-and-resource-optimization.md)。

---

## 一、设计目标

| 目标 | 判据 |
|------|------|
| **美观** | 用户第一反应是"这个软件挺讲究"，而不是"又是一个安装向导" |
| **克制** | 所有选项默认选最保守、最隐私、最干净的方案 |
| **透明** | 明确告知会写什么、写到哪里、怎么删掉 |
| **快速** | 默认路径一键安装 ≤ 30 秒完成 |
| **可跳过** | 想快的用户能一路默认；想细的用户能逐项控制 |
| **可访问** | 亮/暗主题、高 DPI、多语言、纯键盘、屏幕阅读器 |
| **卸载同样精致** | 卸载界面与安装界面品质一致，不是系统默认灰框 |

## 二、视觉设计规范

### 2.1 设计语言

| 维度 | 规范 |
|------|------|
| 风格 | 极简、留白充足、层级清晰、无装饰性插图堆砌 |
| 主色 | 品牌主色 1 种 + 中性灰阶 + 语义色（成功/警告/危险） |
| 圆角 | 统一圆角体系（卡片 12px、按钮 8px、输入框 8px） |
| 阴影 | 轻量、扩散柔和，仅用于层级区分 |
| 字体 | 系统字体优先；中文使用系统中文黑体，避免嵌入大字体文件 |
| 字号 | 标题 24/20px，正文 14px，辅助 12px |
| 间距 | 8px 基准网格 |
| 图标 | 线性图标，统一线宽；仅在必要处使用 |
| 动画 | 150–250ms 缓动；尊重系统"减少动效"设置 |
| 留白 | 内容区最大宽度约 560px，居中，两侧留白充足 |

### 2.2 主题

| 项 | 要求 |
|----|------|
| 亮色主题 | 白/浅灰背景，深色文字，对比度 ≥ 4.5:1 |
| 暗色主题 | 深灰背景（非纯黑，避免刺眼），浅色文字 |
| 默认 | 跟随系统 |
| 切换 | 向导内可实时切换，立即生效 |
| 高对比度 | 支持系统高对比度模式 |

### 2.3 无障碍

| 要求 | 说明 |
|------|------|
| 纯键盘操作 | `Tab` / `Shift+Tab` 移动焦点，`Enter` 确认，`Esc` 后退，`Alt+字母` 快捷键 |
| 焦点可见 | 明确的焦点轮廓（≥ 2px，对比度 ≥ 3:1） |
| 屏幕阅读器 | 全部控件有可访问名称与描述；状态变化有播报；进度变化播报节流 |
| 缩放 | 支持 100%–300% 缩放不错位 |
| 文字大小 | 尊重系统文字大小设置 |
| 语言 | 安装界面支持中/英（至少），并可跟随系统语言 |

### 2.4 窗口规格

| 项 | 值 |
|----|-----|
| 默认尺寸 | 720 × 520（逻辑像素） |
| 最小尺寸 | 640 × 480 |
| 可缩放 | 是（内容自适应，最大宽度限制） |
| 标题栏 | 自绘，品牌一致；保留系统最小化/关闭行为 |
| 关闭行为 | 关闭 = 取消安装（`Esc` 同） |
| 多显示器 | 在光标所在屏幕居中显示 |

## 三、安装向导完整流程

共 **13 步**。其中 5 步可被"一键默认安装"跳过。

```
① 欢迎
② 许可协议
③ 隐私承诺
④ 安装路径
⑤ 数据目录
⑥ 组件选择
⑦ 快捷方式与集成
⑧ 备份目录
⑨ 远程访问选项
⑩ 隐私选项
⑪ 摘要确认
⑫ 安装进度
⑬ 完成
```

**全局元素**（每步都有）：

- **顶部**：品牌标识 + 步骤指示器（如 `4 / 13`，可点击已过步骤返回）
- **中部**：当前步骤内容
- **底部**：`上一步` / `下一步` / `取消`；第 1 步无"上一步"，最后一步为`完成`
- **右下角**：`一键默认安装`（从第 1 步起即可用）

## 五、错误与边界情况

| 情况 | 界面表现 |
|------|---------|
| 磁盘空间不足 | 就地提示：「需要 636 MB，D 盘仅剩 120 MB。请更换位置或清理空间。」并提供"选择其他位置"按钮 |

## 六、静默安装与企业部署

### 6.1 支持（但必须可审计）

| 项 | 要求 |
|----|------|
| 命令行参数 | 全部安装选项都有对应参数 |
| 参数文档 | 完整列出参数名、取值、默认值、示例 |
| 审计日志 | 静默安装生成与交互安装相同的安装清单与日志 |
| 不隐藏行为 | 静默安装与交互安装写入完全相同的内容，不存在"静默模式下多装东西" |
| 退出码 | 明确定义成功/失败/需重启等退出码 |

**参数示例（具体命名以实现为准）**

```
--silent                       静默安装，使用默认值
--install-dir <path>           程序位置
--data-dir <path>              数据目录
--backup-dir <path>            备份目录
--portable                     解压便携版
--components <list>            组件列表
--no-desktop-shortcut          不创建桌面快捷方式
--no-startmenu-shortcut        不创建开始菜单项
--no-autostart                 不开机自启
--no-file-assoc                不关联文件
--auto-backup <on|off>         自动备份
--remote-access <on|off>       远程访问
--log <path>                   输出安装日志
--help                         显示帮助
```

> **红线**：静默安装**不允许**开启任何交互安装中默认关闭的选项。企业管理员可以显式开启，但不能靠参数"偷偷打开"。

### 6.2 企业部署建议

| 场景 | 建议 |
|------|------|
| 批量部署 | 用静默安装 + 统一配置文件 |
| 统一配置 | 支持从指定路径读取配置模板（`--config <path>`） |
| 无网络环境 | 提供离线完整包（含所有可选组件与语言包） |
| 集中更新 | 支持指向自建更新服务器（需在配置中显式指定） |
| 审计要求 | 提供 SBOM 与完整依赖许可证清单 |

### 7.3 卸载失败的处理

| 失败情形 | 界面表现 |
|---------|---------|
| 文件被占用 | 提示"以下文件正被占用，将尝试在重启后删除" + 列出文件 + 「重启后删除」按钮 |
| 权限不足 | 提示「需要管理员权限删除 xxx」+ 提供「以管理员身份重试」 |
| 注册表无法删除 | 列出具体项 + 说明可能原因 + 提供 `.reg` 删除文件供手动执行 |
| 部分失败 | 不中断，继续删其他项，最后汇总报告成功/失败清单 |
| 全部失败 | 明确说明 + 提供详细日志 + 提供手动清理指引 |

## 八、跨平台 UI 差异

| 项 | Windows | Linux | macOS |
|----|---------|-------|-------|
| 默认安装形式 | 安装器 + 便携 zip | AppImage + deb/rpm | .dmg + .app |
| 窗口装饰 | 自绘标题栏 | 跟随桌面环境 | 原生标题栏（macOS 规范） |
| 默认按钮位置 | 右下 | 右下 | **右下（但与 macOS 习惯的"确认在右"一致）** |
| 主快捷键修饰键 | Ctrl | Ctrl | Cmd |
| 菜单 | 窗口内菜单 | 窗口内菜单 | 系统菜单栏 |
| 卸载入口 | 卸载程序 | 移除文件 + 清理脚本 | 应用内卸载脚本 |
| 权限提示 | 无需提权 | 无需提权 | 可能需要"键盘监听"权限（用于全局快捷键），需引导用户在系统设置中授权 |

**全局快捷键权限的特殊说明（macOS）**：截图与全局快捷键需要"辅助功能"或"输入监控"权限。安装/首启时需**明确告知**为什么需要、如何授权、如何撤销，**不允许静默索取**。
