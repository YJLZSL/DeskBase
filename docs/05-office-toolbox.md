# 05 · 办公工具箱详细设计

> 这是产品的**第一印象模块**。大多数用户第一次打开 DeskBase，接触到的不是数据库，是这里。

---

## 一、模块定位

办公工具箱承载「跟结构化查询无关、但跟日常办公强相关」的全部能力。它的设计目标是：

| 目标 | 判据 |
|------|------|
| 零学习成本 | 打开就会用，不需读文档 |
| 快 | 截图到出图 ≤ 300 ms；笔记打开 ≤ 200 ms |
| 全 | 一个软件替代五六个小工具，不必在工具间复制粘贴 |
| 安全 | 剪贴板、截图、OCR 全部本地处理，不上传 |
| 不丢 | 全部内容自动保存，有版本、有回收站 |

二级功能共 **13 个**：笔记、文档、表格、看板、日历、待办、文件、剪贴板历史、截图、OCR、标签、模板、导入导出。

| 编辑器 | Markdown 优先，所见即所得与源码双模式切换 |
| 双向链接 | `[[笔记名]]` 语法，自动建立反向链接 |

| 标签 | 跨模块统一标签 |

| 版本历史 | 每次保存产生版本，可 diff、可回滚 |
| 导出 | Markdown / HTML / PDF / Word（进阶） |

### 2.2 编辑与保存策略

| 策略 | 设计 |
|------|------|
| 自动保存 | 输入停止 **1.5 秒**后触发；可配置 0.5–10 秒 |
| 强制保存 | 切换笔记、关闭窗口、切到后台超过 30 秒时强制提交 |
| 原子写入 | 每次保存为一个事务，写入 WAL 后 `fsync` |
| 草稿保护 | 未提交内容单独存草稿区，崩溃后可恢复 |
| 冲突处理 | 同一笔记在两处打开时，后写者看到合并提示，不静默覆盖 |
| 版本策略 | 每 5 分钟或每 50 次编辑产生一个历史版本；可配 |
| 版本保留 | 默认保留 90 天，可配；可锁定重要版本永久保留 |

### 2.3 崩溃恢复流程

```
检测到上次异常退出
        ↓
扫描草稿区与 WAL
        ↓
┌──────────────────────────────────┐
│ 发现未提交内容：                 │
│  · 《会议记录》  2 分钟前  1.2 KB │
│  · 《采购清单》  8 分钟前  340 B  │
└──────────────────────────────────┘
        ↓
  [恢复全部]  [逐条查看]  [丢弃]
        ↓
恢复后自动创建一次快照（防止二次损坏）
```

## 九、截图系统 ★ 重点设计

截图是本产品最高频、最容易做出差异化的能力之一。它由**捕获 → 标注 → 输出 → 归档**四个阶段组成。

```
┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐
│  捕获   │ → │  标注   │ → │  输出   │ → │  归档   │
│ 区域/窗口│   │ 箭头/文字│   │ 复制/保存│   │ 历史/OCR│
│ 全屏/延时│   │ 马赛克等 │   │ 贴图/分享│   │ 检索/清理│
│ 滚动/拼接│   │         │   │         │   │         │
└─────────┘   └─────────┘   └─────────┘   └─────────┘
```

### 9.1 捕获方式

| 方式 | 默认快捷键 | 行为 |
|------|-----------|------|
| 区域截图 | `Ctrl/Cmd + Shift + A` | 拖拽选区；显示尺寸与坐标；`Shift` 锁定正方形；`Alt` 从中心缩放 |
| 窗口截图 | `Ctrl/Cmd + Shift + W` | 鼠标悬停高亮窗口边界，点击即截；支持子窗口/控件级 |
| 全屏截图 | `Ctrl/Cmd + Shift + F` | 当前屏幕；`Ctrl` 组合键可截全部屏幕 |
| 延时截图 | `Ctrl/Cmd + Shift + D` | 倒计时 1–30 秒（可配），倒计时内可取消 |
| 滚动长截图 | `Ctrl/Cmd + Shift + S` | 见 9.2 |
| 长图拼接 | `Ctrl/Cmd + Shift + M` | 见 9.3 |
| 重复上次区域 | `Ctrl/Cmd + Shift + R` | 用上次的选区直接截 |
| 剪贴板转存 | — | 把剪贴板里的图片存入截图历史 |

### 9.2 滚动长截图（核心差异化能力）

**两种模式**

| 模式 | 适用场景 | 机制 |
|------|---------|------|
| **自动滚动** | 浏览器、聊天记录、长列表、PDF 阅读器 | 程序模拟滚动事件，逐屏捕获并拼接 |
| **手动滚动** | 游戏界面、远程桌面、特殊渲染的应用、滚动会被劫持的页面 | 用户自己滚动，每次滚动后程序自动捕获，实时预览拼接结果 |

**自动滚动流程**

```
1. 用户选定区域（或自动识别可滚动容器）
2. 程序记录初始帧
3. 循环：
   a. 发送滚动指令（步长 = 视口高度 × 步进系数）
   b. 等待渲染稳定（检测画面变化停止 / 固定延迟，取先满足者）
   c. 捕获新帧
   d. 与已拼接结果做重叠检测（模板匹配 / 像素相似度）
   e. 计算重合偏移，裁掉重复部分后追加
   f. 检测是否到达底部（画面不再变化 / 出现固定底部元素）
4. 生成结果，显示预览
5. 用户确认 / 手动裁剪 / 保存
```

**关键技术点**

| 问题 | 对策 |
|------|------|
| 滚动步长过大导致漏内容 | 步长默认 **视口高度 × 0.7**，保证 30% 重叠；可配 |
| 固定页头/页脚导致重复 | 检测并识别固定元素，在拼接时排除；提供手动"忽略顶部/底部 N 像素" |
| 懒加载内容未渲染完就截 | 每帧等待渲染稳定（连续两帧差异 < 阈值）后再截，含最长等待超时 |
| 动画导致拼接错位 | 检测到持续变化时延长等待，并提示用户"页面有动画，建议关闭" |
| 长图过长（内存压力） | 分块拼接，边拼边写临时文件；最大高度默认 30 000 px，可配 |
| 拼接接缝可见 | 用渐变混合（feather）处理接缝，宽度默认 8 px |
| 无法检测到滚动 | 3 次无变化后提示切换到手动模式 |

**长截图输出**

- 预览窗口显示完整长图，可缩放、可拖动
- 可手动裁剪顶部/底部
- 可随时中止并保留已拼接的部分
- 保存为 PNG（无损）或 WebP（体积小），分片保存可选

**三级设置（长截图）**

| 设置项 | 默认值 | 说明 |
|-------|-------|------|
| 滚动步进系数 | 0.7 | 相对于视口高度 |
| 最大高度 | 30 000 px | 超出后停止并提示 |
| 拼接去重灵敏度 | 中 | 低/中/高，影响重叠检测阈值 |
| 渲染稳定等待上限 | 1500 ms | 超时则强制捕获 |
| 接缝混合宽度 | 8 px | 0 表示不混合 |
| 自动滚动间隔 | 200 ms | 每次滚动后的基础等待 |

## 十三、导入导出

### 13.1 导入

| 格式 | 能力 |
|------|------|
| CSV | 分隔符/编码/引号规则识别，表头识别，类型推断，字段映射 |
| TSV | 同上 |

**导入向导步骤**

```
选择文件 → 预览前 20 行 → 配置编码/分隔符 → 字段映射与类型
        → 冲突处理策略 → 试导入校验 → 正式导入 → 错误报告
```

**冲突策略**：跳过 / 覆盖 / 追加为新行 / 按主键更新。

**错误处理**：导入不因单行错误而中断；错误行生成报告，可下载修正后重试。

### 13.2 导出

| 格式 | 用途 |
|------|------|
| CSV | 通用，最便携 |
| TSV | 便于粘贴进 Excel |
| JSON | 保留结构与嵌套 |
| Excel | 带格式的交付 |
| Markdown | 笔记导出 |
| SQL | 数据库结构与数据 |
| HTML | 可打印的报表 |
| PDF | 归档与打印（进阶） |

**导出选项**：导出范围（全部/筛选结果/选中行）、是否含表头、编码、是否脱敏（进阶）、是否分文件（按什么字段拆）。

### 13.3 一键全量导出（可迁移性保障）

`设置 → 基础 → 导出全部数据` 生成一个目录：

```
deskbase-export-20260917/
├── README.txt          ← 用纯文本说明每个文件是什么、怎么打开
├── manifest.json       ← 文件清单、大小、校验和
├── notes/              ← 每篇笔记一个 .md 文件
├── tables/             ← 每个表格一个 .csv
├── databases/          ← 数据库导出为 .sql
├── attachments/        ← 附件原文件
├── templates/          ← 自定义模板
├── config/             ← 设置（脱敏后）
└── checksums.sha256
```

> **README.txt 必须用人类可读的普通文字写**，不能只有机器可解析的格式。用户十年后打开这个文件夹，即使 DeskBase 已经不存在，也应该能看懂里面是什么。


每一步都有 `跳过` 与 `下一步`；全部完成后可选「生成示例数据继续探索」。

### 15.4 示例数据

| 内容 | 说明 |
|------|------|
| 生成方式 | 一键生成，写入独立的「示例」库/表格/笔记 |
| 内容 | 一份客户表（20 行）、一份订单表（50 行）、3 篇笔记、一些待办 |
| 用途 | 供教程练习、供用户体验查询功能、供截图演示 |
| 清除 | 帮助模块内「清除示例数据」一键完成，彻底删除，不留痕迹 |
| 隔离 | 示例数据放在独立文件，不与用户数据混在一起 |

## 十六、办公工具模块三级设置总览

```
办公工具
├── 笔记        → 编辑 / 保存 / 显示 / 高级
├── 文档        → 版式 / 导出
├── 表格        → 显示 / 编辑 / 数据 / 性能
├── 看板        → 卡片字段 / 列行为 / 动画
├── 日历        → 默认视图 / 工作时间 / 提醒 / 显示
├── 待办        → 默认清单 / 显示规则 / 每日重置
├── 文件        → 索引目录 / 监视 / 预览 / 回收站
├── 剪贴板      → 记录范围 / 容量 / 隐私 / 排除项
├── 截图        → 快捷键 / 保存 / 行为 / 长截图 / 历史 / 高级
├── OCR         → 语言 / 模式 / 输出 / 性能
├── 标签        → 层级 / 颜色 / 排序
├── 模板        → 分类 / 创建行为 / 显示
└── 导入导出    → 默认格式 / 编码 / 编码默认值 / 冲突策略
```
