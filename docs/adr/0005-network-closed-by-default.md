# ADR-0005: 网络访问默认关闭

- **状态**：已接受
- **日期**：2026-09-17
- **决策者**：核心维护者
- **相关**：[08 · 隐私、安全、加密、权限与审计](../08-privacy-security.md)、[ADR-0001](0001-local-first-architecture.md)

---

## 背景

现代桌面应用普遍默认联网：启动时检查更新、加载在线字体、上报崩溃、同步配置、发送使用统计。这些行为通常不告知用户，或在隐私政策中用模糊措辞带过。

本项目宣称"默认无遥测、无云端上传、数据不出本机"。要让它成立，必须解决一个具体问题：**程序在什么条件下被允许联网？**

如果采取"默认开启部分联网（如更新检查），其他关闭"的做法，用户将无法确定程序是否真的没在传数据——因为"部分联网"本身就破坏了可验证性。

---

## 决策

**网络访问默认完全关闭。程序在用户未显式开启之前，不建立任何外部连接。**

具体要求：

1. 设置中提供**网络总开关**（默认关闭），作为最高优先级控制。
2. 即使总开关开启，每个联网功能仍有独立开关，且**各自默认关闭**：
   - 检查更新（默认关闭，提供手动检查）
   - 下载 AI 模型（默认关闭，每次下载需确认）
   - 远程访问（默认关闭）
   - 局域网发现（默认关闭）
   - 自托管同步（默认关闭）
   - 外部 AI 服务（默认关闭）
   - 插件网络访问（默认关闭，逐插件授权）
3. **不存在**遥测、埋点、崩溃上报、使用统计的开关 —— 因为功能不存在。
4. 全部出站连接尝试记入本地**审计日志**，用户可查看、导出。
5. 提供**网络自证视图**：显示当前活动连接数、出站尝试次数、被拒绝次数。
6. 网络功能关闭时，**网络 IO 必须为 0 字节**（硬性指标）。

---

## 备选方案

### 方案 A：默认开启更新检查
- 优点：用户能及时获得安全更新；符合行业惯例
- 缺点：破坏"启动时不联网"的可验证性；用户无法区分"检查更新"与"上报数据"；在某些环境下（企业、涉密）属于违规行为
- **为什么不选**：安全更新的价值不值得牺牲可验证性。我们提供**手动检查更新**，并在程序内提示是否有可用安全更新。

### 方案 B：默认开启匿名崩溃上报（可关闭）
- 优点：能及时发现崩溃问题，提升质量
- 缺点：崩溃堆栈可能包含文件路径、数据片段等隐私信息；"匿名"难以被用户验证
- **为什么不选**：隐私承诺的边界不能靠"我们做了脱敏"来维持。崩溃信息写入本地日志，用户可自行决定是否提交到 Issue。

### 方案 C：默认开启，但提供"隐私模式"一键关闭
- 优点：兼顾默认体验与隐私需求
- 缺点：默认状态下用户已经暴露；大多数用户不会去关；"隐私模式"成为免责工具
- **为什么不选**：把隐私变成"需要主动争取的选项"是错的。隐私应该是默认状态。

### 方案 D：首次启动时让用户选择
- 优点：用户有知情权
- 缺点：用户往往不读说明直接点"下一步"；选择结果不一致导致行为不可预测；且仍需保留默认值
- **为什么不选**：我们在安装向导中**告知**网络默认关闭这件事，但不把它做成一个可被无意识跳过的选择题。

## 后果

### 正面
- "启动不联网"成为可验证的事实，而非承诺
- 在网络受限环境（内网、涉密、弱网、计量网络）下无副作用
- 用户可用抓包自行验证，建立真实信任
- 不引入任何第三方 SDK 依赖，减小体积与供应链风险
- 企业部署无障碍（很多企业禁止软件外联）

### 负面
- 用户不会自动收到更新，可能长期停留在有已知缺陷的版本
  - 缓解：程序内显示"距上次更新检查已 N 天"；启动时在界面（非网络）提示可手动检查；安全更新在版本号中标注
- 首次使用 AI 功能需要额外操作（下载模型）
  - 缓解：在 AI 功能首次使用时引导下载，说明来源与体积

### 中性
- 需要额外实现审计日志与网络自证视图，增加工程量
- 需要为"手动检查更新"设计不打扰用户的提示方式

---

## 验证方式

| # | 验证项 | 判据 |
|---|-------|------|
| 1 | 默认状态连接数 | 全新安装后启动，5 分钟内外部连接数 = 0 |
| 2 | 网络 IO = 0 | 网络功能关闭时，系统计数器显示 0 字节 |
| 3 | 抓包验证 | 抓包结果中无任何外部目标 |
| 4 | 无遥测代码 | 代码扫描 + 依赖审查：无分析/上报类库 |
| 5 | 审计日志完整性 | 每次出站尝试都被记录（含被拒绝的） |
| 6 | 手动更新可用 | 用户可主动检查更新并看到结果 |
| 7 | 断网可用 | 拔网线后全部核心功能正常 |
