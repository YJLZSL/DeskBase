# ADR-0024 · 修订 v1.0.0 的门槛（解决"永远达不到"的三条）

- 状态：已接受
- 日期：2026-09-23
- 关联：Q-045（本 ADR 即其裁决）、`VERSION_PLAN.md` 3.5

---

## 1. 背景

`VERSION_PLAN.md` §3.5 把 v1.0.0 的门槛写死了五条。其中有**三条与已生效的决定直接矛盾**，
结果是：**v1.0.0 在任何时间点都达不到**（不是"还没做到"，是"定义上做不到"）。

| # | 门槛原文 | 冲突的已生效决定 |
|:-:|---------|-----------------|
| ① | M0–M8 **全部**验收标准达标 | 路线图里 M5 本地 AI / M6 远程与移动 / M7 自动化与插件 都排在 v1.0 **之后**（`ROADMAP.md`），且 M6 与「只做 Windows」在范围上就不相容 |
| ③ | **三平台**体验一致（Windows / Linux / macOS） | 「只做 Windows」（Q-001 已定，ADR-0010） |
| ⑤ | 发布链完整：**签名**、校验和、SBOM、可复现构建 | 「不购买代码签名证书」（2026-09-18 已定） |

Q-045 已把这个矛盾拎出来，并写明：**必须走 RFC / 新 ADR 正式修订门槛，不能悄悄放水。** 本 ADR 就是那次正式修订。

## 2. 决策

按下面三条修订门槛。**修订的是"门槛的措辞"，不是"放低要求"** —— 每条改写后都仍然可验证。

### ① M0–M8 → 「M0–M4 + M8 达标，M5/M6/M7 移出 v1.0 门槛」

- v1.0 判定范围：**M0（地基）、M1（办公台）、M2（表格）、M2.5/2.6（扩展方向）、M3（不丢数据）、M4（隐私与安全）、M8（体验与性能）**
- M5 本地 AI / M6 远程与移动 / M7 自动化与插件：**明确为 v1.0 之后的独立议题**，不在 v1.0 的判定范围内
- 理由：门槛应当只约束"这个版本承诺过的东西"。把路线图里本就排在后面的里程碑写进 v1.0 门槛，
  等于给 v1.0 加了一条它自己都没承诺过的义务。

### ③ 三平台 → 「目标平台（Windows）内的体验一致」

- 判定口径：Windows 上**便携版与安装版行为一致**（同一份产物、同一套数据目录规则、
  同一套卸载结果）
- 跨平台能力：作为 v1.0 之后的独立议题，不在门槛内
- 理由：「只做 Windows」是已接受的决定（ADR-0010）。要求"三平台一致"在定义上与之互斥。

### ⑤ 签名 → 「签名**或等效的完整性链路**」

无签名证书时，以下五件必须**全部**具备，且每一件都可验证：

1. **SHA-256 校验和**随产物发布（`package.cjs` 产出，已具备）
2. **SBOM**（CycloneDX）随产物发布（已具备）
3. 发布页与界面**如实说明** SmartScreen 会拦截、为什么没有签名（不许假装没有）
4. **不做自替换**的更新路径要么明确关闭，要么按 ADR-0018 的五步校验链执行（现状：默认关闭）
5. 自替换的校验链只认"同 Release 的 SHA-256"，并在文档里写明其局限（账号被攻破则整条链失效）

将来若购买证书，按 ADR-0018 补齐签名那一段。

## 3. 理由

- **不可达的门槛等于没有门槛。** 一个永远达不到的标准，实际作用是让"达标"这件事失去意义，
  也让真实进度无法被判断 —— 这正是本项目最忌讳的含混。
- **修订后每条都可验证**，没有一条靠"看起来差不多"。
- 修订**没有**降低对已承诺能力的任何要求：不丢数据、零污染、本地优先三条承诺一条没动。

## 4. 被否决的方案

| 方案 | 为什么不 |
|------|---------|
| 维持原门槛，继续挂着 | 定义上不可达，等于把 v1.0 变成一个永远不会到来的版本号 |
| 直接发 v1.0.0，不修订 | 这就是 Q-045 明令禁止的"悄悄放水" |
| 把门槛改成"发起人认为可以即可" | 判据变成主观，失去可验证性，正是门槛要防的事 |

## 5. 影响

- `VERSION_PLAN.md` §3.5 按本 ADR 改写；§4 长期债务表与门槛的关系一并注明。
- `OPEN_QUESTIONS.md` Q-045 标记为已裁决（本 ADR）。
- **v1.0.0 由此变为"可达"** —— 但可达不等于已达。当前仍差的具体条目见
  `local-docs/handoff/VERSION_PLAN.md` §3.5 后的"当前差距清单"（每次发版更新）。
