# ADR-0008: 便携版优先，安装版采用用户级安装

- **状态**：已接受
- **日期**：2026-09-17
- **决策者**：核心维护者
- **相关**：[11 · 安全与资源优化专项](../11-security-and-resource-optimization.md)、[12 · 安装与卸载体验](../12-installer-and-uninstaller.md)

---

## 背景

桌面软件在 Windows 上的惯例是：需要管理员权限，安装到 `Program Files`，写入 `HKLM`（机器级注册表），注册卸载信息、文件关联、开机自启、右键菜单。

这种做法带来几个问题：

- 需要提权（用户看到 UAC 弹窗会犹豫）
- 卸载常常清不干净（散落在 `HKLM`、`%AppData%`、`%ProgramData%` 多处）
- 一台机器上装多个版本会冲突
- 用户无法"试一下就走"
- 企业环境往往禁止用户安装到系统目录

本项目把"零污染"和"默认最小权限"列为核心原则。要让它成立，必须重新设计安装形态。

---

## 决策

**默认推荐便携版（解压即用、零注册表写入）；安装版采用用户级安装（`HKCU` + 用户目录），不需管理员权限；全用户安装作为显式可选项（需主动勾选并说明代价）。**

具体要求：

1. **便携版**：
   - 解压即用，不写注册表、不写系统目录、不装服务、不建计划任务、不改文件关联、不装驱动、不开机自启
   - 数据默认放程序目录或用户指定目录
   - 可随 U 盘移动，换机即用
   - 手动更新（下载新版本覆盖）

2. **安装版**：
   - 默认安装到 `%LocalAppData%\Programs\DeskBase`
   - 数据目录默认 `%UserProfile%\DeskBaseData`（与程序分离）
   - 只写 `HKCU\Software\DeskBase`（约 12 个值）+ 系统要求的卸载信息项
   - **不写 `HKLM`**（除用户显式选择全用户安装）
   - 快捷方式、文件关联、开机自启、右键菜单**全部默认关闭**（除开始菜单项）
   - 生成 `install-manifest.json`，记录创建的每一项，供卸载精确清理

3. **安装向导第一步就让用户选择**"安装版"还是"仅解压便携版"。

4. **卸载提供两档**：保留数据卸载 / 彻底清除卸载（后者需输入确认词）。

5. **卸载后残留项必须为 0**（彻底清除模式），并出具残留检查报告。

---

## 备选方案

### 方案 A：传统系统级安装（Program Files + HKLM）
- 优点：符合 Windows 惯例；多用户共享一份程序文件；与某些企业软件分发工具兼容性更好
- 缺点：需要管理员权限；卸载更难清干净；一台机器只能装一个版本；用户试用成本高
- **为什么不选**：违反"默认最小权限"与"零污染"承诺。作为**可选**保留（用户主动勾选"为所有用户安装"）。

### 方案 B：仅提供便携版
- 优点：最干净；实现最简单
- 缺点：没有开始菜单项，用户不方便找到；无法做自动更新；多人共用电脑时数据隔离差
- **为什么不选**：对长期使用的普通用户不够友好。安装版仍有其价值。

### 方案 C：便携版优先 + 用户级安装（采纳）
- 优点：默认干净、默认不需提权、卸载可控、支持试用与长期使用两种场景
- 缺点：需要自己实现安装器（不能用最省事的标准方案）；需要在文件关联等场景下处理用户级注册
- **为什么选它**：唯一同时满足"零污染""最小权限""可试用"与"长期可用"的方案。

### 方案 D：AppImage / 免安装为主（仅 Linux）
- 优点：Linux 上最干净的方案
- 缺点：仅适用 Linux
- **决策**：Linux 上**优先提供 AppImage**，同时提供 deb/rpm 作为可选项。

## 后果

### 正面
- 用户无需管理员权限即可安装，UAC 弹窗消失
- 卸载可控且可验证，长期不累积系统垃圾
- 便携版让用户"零成本试用"，降低采纳门槛
- 多人共用电脑时，用户级安装天然实现数据隔离
- 企业环境中用户可自行安装（无需 IT 介入）
- 与"可随 U 盘携带、换机即用"的产品亮点一致

### 负面
- **需要自建安装器**（或选择支持自绘与用户级安装的框架），开发成本高于使用现成方案
  - 缓解：由 ADR-0010 与后续 ADR 决定安装器技术方案
- 文件关联在用户级注册表下作用范围有限（仅当前用户）
  - 接受：文件关联本就默认关闭，且用户级关联对个人使用足够
- 自动更新在用户级安装下需要额外设计（无服务、无计划任务）
  - 缓解：更新时下载新版本并替换，在下次启动生效；或用便携版式更新（下载完整包）
- 某些企业分发工具默认寻找 `HKLM` 卸载信息
  - 缓解：提供静默安装参数与文档；企业版可选用显式全用户安装

### 中性
- 产品定位为"个人工具"而非"企业软件"，用户级安装与定位一致
- 需要严格控制注册表写入项（每加一项都要有充分理由）

## 验证方式

| # | 验证项 | 判据 |
|---|-------|------|
| 1 | 便携版零注册表 | 运行便携版后，注册表快照与运行前对比差异 = 0 |
| 2 | 安装不需提权 | 标准用户账户下可完成安装 |
| 3 | 不写 HKLM | 注册表快照：`HKLM` 下无本项目相关项 |
| 4 | 注册表项数 | `HKCU\Software\DeskBase` 下的值 ≤ 15 个，且全部用于卸载 |
| 5 | 卸载零残留 | 干净虚拟机：安装 → 使用 → 彻底清除卸载 → 残留项 = 0 |
| 6 | 安装清单完整 | `install-manifest.json` 覆盖全部创建的项（注册表/快捷方式/关联/启动项/防火墙规则） |
| 7 | 便携版可移动 | 数据目录在 U 盘上，换机器后可正常使用 |
| 8 | 安装无网络 | 断网环境下可完成安装 |
