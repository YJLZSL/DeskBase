# 08 · 隐私、安全、加密、权限与审计设计

> 隐私不是设置里的一个开关。它是**默认状态**，是**架构约束**，是**可以被验证的事实**。

---

## 一、隐私立场

### 1.1 三条承诺

| 承诺 | 含义 | 可验证方式 |
|------|------|-----------|
| **不收集** | 不存在遥测、埋点、崩溃上报、使用统计、设备指纹 | 抓包 + 断网运行 + 审阅源码 |
| **不外传** | 除用户显式授权的操作外，用户数据不离开设备 | 抓包 + 审计日志 + 网络总开关 |
| **不隐瞒** | 程序在哪些目录写了什么、何时联网，用户都能看到 | 「我本机存了什么」视图 + 审计日志 |

### 1.2 不是承诺的部分（诚实声明）

我们必须对用户诚实，以下能力**不提供**：

| 不提供 | 原因 |
|-------|------|
| 防物理接触攻击 | 若攻击者能物理接触设备且知道口令，加密数据可被读取。这是我们能力的边界 |
| 防键盘记录器 / 屏幕录制 | 属操作系统级威胁，超出应用层能力 |
| 防内存取证 | 运行中的明文数据在内存中，超出应用层能力 |
| 防恶意插件 | 插件虽有沙箱与权限隔离，但用户主动安装恶意插件仍有风险 |
| 防用户自己泄露 | 用户导出后自行上传，我们无法控制 |

**在文档和界面上都必须明说这些边界**，而不是营造"绝对安全"的错觉。

## 二、数据分类与处理规则

### 2.1 四级分类

| 级别 | 定义 | 示例 | 存储 | 加密 | 外发 |
|------|------|------|------|------|------|
| **S0 公开** | 不含任何用户信息 | 界面文案、内置模板、内置词典、示例数据 | 程序目录 | 否 | 可随程序分发 |
| **S1 个人** | 用户个人内容 | 笔记、待办、日历、表格、文件名、标签 | 数据目录 | 跟随全局设置 | **不主动外发** |
| **S2 敏感** | 泄露会造成实质损害 | 密码字段、证件号、财务记录、截图内容、OCR 结果、AI 对话 | 数据目录 | **默认加密**（开启加密时） | **永不外发** |
| **S3 机密** | 用户显式标记为机密 | 用户手动标记的库/表/笔记 | 数据目录 | **强制加密** | **永不外发**，不进备份明文 |

### 2.2 各级处理规则

**S1**
- 默认本地存储。
- 可通过用户显式配置的同步/远程功能传输（端到端加密）。
- 可进入备份。

**S2**
- 存储时加密（字段级或库级）。
- 绝不允许进入任何外部 AI 请求体。
- 进入备份时必须加密。
- 导出时默认脱敏（用户可显式关闭，但会看到警告）。

**S3**
- 强制加密，不可关闭。
- 打开需重新验证身份。
- 导出需二次确认。
- 备份中包含时，备份也必须加密（否则拒绝备份并提示）。

### 2.3 数据分类的落地

| 机制 | 说明 |
|------|------|
| 字段级标记 | 建字段时可标记为"敏感"，该字段自动加密 |
| 自动识别 | 检测疑似手机号/身份证号/银行卡号的字段，**建议**标记为敏感（不强制） |
| 库级标记 | 整个库可标记为机密 |
| 全局策略 | 设置中可定义"哪些字段名默认视为敏感"（如 `password`、`身份证`） |

## 三、网络行为策略

### 3.1 网络总开关（最高优先级）

```
设置 → 隐私与安全 → 网络访问
┌──────────────────────────────────────────────────────┐
│  网络访问                                  [ ● 关闭 ]│
│                                                      │
│  默认关闭。开启后，以下操作才可能联网：                │
│    · 检查更新                                        │
│    · 下载本地 AI 模型                                 │
│    · 远程访问                                        │
│    · 同步                                            │
│    · 外部 AI 服务                                    │
│                                                      │
│  ⓘ 关闭时，全部本地功能不受影响。                      │
│                                                      │
│  当前状态：已关闭   （本程序当前未建立任何网络连接）    │
│                                       [ 查看审计日志 ]│
└──────────────────────────────────────────────────────┘
```

**总开关关闭时**：程序在网络层直接拒绝全部出站连接（在应用层与操作系统防火墙规则双重保证，尽力而为）。

### 3.2 分项开关

即使总开关开启，每个联网功能也有独立开关，且**默认关闭**：

| 功能 | 默认 | 说明 |
|------|------|------|
| 检查更新 | 关闭 | 用户可手动检查 |
| 下载 AI 模型 | 关闭 | 每次下载需确认，显示来源与哈希 |
| 远程访问 | 关闭 | 开启后仍需配置权限 |
| 局域网发现 | 关闭 | 依赖远程访问开启 |
| 自托管同步 | 关闭 | 需配置服务器地址 |
| 外部 AI 服务 | 关闭 | 需配置 + 逐次授权 |
| 插件网络访问 | 关闭 | 逐插件授权 |
| 图床上传（插件） | 未安装 | 需显式安装插件 |

### 3.3 连接审计

**每一次网络连接都必须被记录**：

| 记录项 | 内容 |
|-------|------|
| 时间 | 精确到秒 |
| 目标 | 域名 / IP / 端口 |
| 协议 | HTTPS / WSS / TCP 等 |
| 触发原因 | 用户操作 / 定时任务 / 更新检查 |
| 关联功能 | 属于哪个模块 |
| 数据传输量 | 上行 / 下行字节数 |
| 结果 | 成功 / 失败 / 被拒绝 |
| 是否加密 | 传输层 + 应用层 |

**用户可查看、可导出、可筛选**。审计日志本身有容量上限并自动轮转。

### 3.4 不联网的证明

程序提供一个**「网络自证」界面**：

```
网络行为自证
────────────────────────────────────────────────
自 2026-09-17 08:00 启动以来：

  出站连接尝试：0 次
  被拒绝的连接：0 次
  当前活动连接：0 个
  审计日志记录：0 条

  网络总开关：关闭
────────────────────────────────────────────────
[ 打开系统网络监视器 ]  [ 导出审计日志 ]
```

> 这不是"我们相信我们没联网"，而是"你可以自己看"。

## 四、加密体系

### 4.1 加密层次

| 层次 | 对象 | 算法 | 密钥来源 | 默认 |
|------|------|------|---------|------|
| **传输加密** | 远程访问通道 | TLS 1.3 + 应用层 E2EE | 配对时协商 | 强制 |
| **备份加密** | 备份包 | AEAD（AES-256-GCM / ChaCha20-Poly1305） | 口令派生 或 主密钥 | 跟随主库 |
| **库级加密** | 数据库文件 | 页级 AEAD | 口令派生 或 系统密钥链 | 首启询问 |
| **字段级加密** | 敏感字段值 | AEAD | 主密钥 | S2/S3 自动 |
| **附件加密** | 附件文件 | AEAD（分块） | 主密钥 | 跟随库级 |
| **配置加密** | 含敏感项的配置 | AEAD | 主密钥 | 自动 |
| **缓存** | 可重建数据 | 不加密 | — | — |

### 4.2 密钥管理

```
用户口令
   │
   ├── KDF（Argon2id：内存 64MB、迭代 3、并行 4）── 参数记录在文件头
   │
   ↓
主密钥（Master Key，随机生成，永不直接暴露）
   │
   ├── HKDF 派生 → 库加密密钥（按库 ID 区分）
   ├── HKDF 派生 → 字段加密密钥（按字段 ID 区分）
   ├── HKDF 派生 → 备份加密密钥（按备份 ID 区分）
   ├── HKDF 派生 → 附件加密密钥（按文件 ID 区分）
   └── HKDF 派生 → 完整性校验密钥
```

**关键设计**

| 设计 | 理由 |
|------|------|
| **主密钥随机生成，由口令派生密钥加密后存储** | 改口令时只需重新加密主密钥，不必重新加密全部数据 |
| **按对象派生不同密钥** | 避免密钥复用；单一密钥泄露不危及全部数据 |
| **KDF 参数记录在文件头** | 未来可升级 KDF 强度而不破坏旧数据 |
| **密钥不出现在日志、内存转储提示、错误信息中** | 防止意外泄露 |
| **密钥不进入备份包** | 备份包被拿走 ≠ 数据被拿走 |
| **内存中密钥可被主动清除** | 锁定/退出时清零密钥缓冲区（尽力而为） |

### 4.3 密钥存储选项

| 方式 | 安全级别 | 便利性 | 适用 |
|------|---------|-------|------|
| 每次输入口令 | 高 | 低 | 高敏感场景 |
| 系统密钥链（Keychain / Credential Manager / libsecret） | 中高 | 高 | **默认** |
| 记忆到本次会话 | 中 | 中 | 平衡选项 |
| 恢复码（离线保存） | 高 | — | 口令丢失时的唯一出路 |

### 4.4 口令与恢复码

| 项 | 设计 |
|----|------|
| 口令强度检测 | 实时提示弱口令，但不强制（用户有选择权） |
| 口令修改 | 重新加密主密钥，不重新加密全部数据；速度快 |
| **恢复码** | 生成 24 字符恢复码，用 Base32 编码，分组显示；**用户必须自己抄写或打印保存** |
| 恢复码用途 | 忘记口令时用恢复码重置口令 |
| 恢复码存储 | 我们不存储。用户丢失恢复码 + 忘记口令 = 数据不可恢复 |
| 明确告知 | 开启加密时必须勾选「我已保存恢复码，并理解丢失后数据不可恢复」 |

### 4.5 加密的性能影响

| 场景 | 加密后性能变化 |
|------|--------------|
| 库打开（10 万行） | +100～200 ms |
| 查询（内存页命中） | 无明显影响 |
| 查询（需解密页） | +10～30% |
| 批量导入 10 万行 | +20～40% |
| 备份（含加密） | +30～50% |

**优化手段**：分块加密、页级加密避免整库解密、随机数生成复用、优先使用硬件 AES 加速指令。

## 五、权限模型

### 5.1 本地权限（单机）

单机场景下，权限主要解决"防止自己误操作"与"临时借给别人用"：

| 机制 | 说明 |
|------|------|
| 库口令 | 加密库需口令解锁 |
| 只读打开 | 以只读模式打开库，防止误改 |
| 敏感表保护 | 指定表需再次验证 |
| 导出限制 | 库/表可标记"禁止导出" |
| 操作确认 | 破坏性操作需输入对象名确认 |
| 会话锁定 | 可设置空闲 N 分钟后锁定（需口令解锁） |

### 5.2 远程权限（多设备）

**权限粒度（五维）**

```
数据库 → 表 → 字段 → 操作 → 时段
```

| 维度 | 可选项 |
|------|-------|
| 数据库 | 指定一个或多个库（或全部） |
| 表 | 库内的指定表（或全部） |
| 字段 | 表内的指定字段；支持"隐藏某些字段"（如身份证号） |
| 操作 | 读 / 增 / 改 / 删 / 导出 / 执行查询 / 管理结构 |
| 时段 | 允许访问的时间窗口（如工作日 9:00–18:00） |

**客户端权限编辑器示意**

```
设备：小林的 iPad（已配对 2026-09-15）
────────────────────────────────────────────
数据库权限：
  ☑ 客户库
      ☑ 客户表      ☑ 读  ☐ 增  ☐ 改  ☐ 删  ☐ 导出
         隐藏字段：☑ 身份证号  ☑ 银行账号
      ☑ 订单表      ☑ 读  ☐ 增  ☐ 改  ☐ 删  ☐ 导出
  ☐ 财务库（不授权）

时段限制：工作日 09:00 – 18:00
连接限制：仅局域网直连（不允许中继）

[ 保存 ]  [ 立即吊销该设备 ]  [ 查看该设备操作记录 ]
```

### 5.3 权限的默认值原则

| 场景 | 默认 |
|------|------|
| 新配对设备 | **只读**，且仅限用户显式选择的库表 |
| 远程修改数据 | 关闭 |
| 远程导出 | 关闭 |
| 远程管理结构 | 关闭 |
| 中继访问 | 关闭（仅局域网） |
| 权限有效期 | 90 天，到期需重新授权 |

## 六、审计日志

### 6.1 记录范围

| 类别 | 默认记录 | 说明 |
|------|---------|------|
| 网络连接 | ✅ | 全部出站连接 |
| 结构变更 | ✅ | DDL 操作 |
| 数据变更 | ✅（仅统计） | 记录"改了多少行"，默认不记录具体值 |
| 查询语句 | ❌ | 默认关闭（可能泄露业务信息） |
| 导出操作 | ✅ | 导出了什么、多大、到哪 |
| 远程连接 | ✅ | 设备、时间、操作摘要 |
| 权限变更 | ✅ | 授权/吊销记录 |
| 加解密操作 | ✅ | 开启/关闭加密、改口令、密钥轮换 |
| 提权操作 | ✅ | 需要管理员权限的操作 |
| 插件行为 | ✅ | 插件权限请求与敏感操作 |
| 应用启动退出 | ✅（简化） | 时间戳，不含使用时长统计 |

### 6.2 日志性质

| 属性 | 说明 |
|------|------|
| 位置 | 数据目录 `logs/audit/`，**仅本地** |
| 格式 | 结构化（JSON Lines），便于用户自己分析 |
| 加密 | 跟随全局加密设置 |
| 容量 | 默认上限 100 MB，超出后轮转 |
| 轮转 | 按大小或时间轮转，保留最近 N 个 |
| 查看 | 应用内提供筛选、搜索、导出 |
| 清空 | 支持（二次确认，告知清空后无法追溯） |
| **不上报** | 审计日志绝不发送到任何地方 |

## 七、运行时安全

### 7.1 最小权限运行

| 要求 | 说明 |
|------|------|
| 默认不要求管理员权限 | 便携版与安装版默认以普通用户权限运行 |
| 需要提权时说明原因 | 如注册文件关联，弹窗说明"此操作需要系统权限，原因：…" |
| 提权最小化 | 只把需要提权的最小操作放到提权进程，主进程不提权 |
| 无提权时不降级功能 | 拒绝提权时功能应优雅降级，而非崩溃 |
| 不申请无关权限 | 不开麦克风除非启用语音转写；不开摄像头除非未来有相关功能 |

### 7.2 进程隔离

```
┌─────────────────────────────────────────────────────┐
│  主进程（无 UI，无网络，最小权限）                     │
│   · 数据访问仲裁                                      │
│   · 密钥管理                                          │
│   · 文件系统操作                                      │
└─────────────────────────────────────────────────────┘
        ↑ IPC（受控接口，逐次鉴权）
┌─────────────────────────────────────────────────────┐
│  UI 进程（渲染，无文件系统直访权限）                   │
└─────────────────────────────────────────────────────┘
        ↑ IPC
┌─────────────────────────────────────────────────────┐
│  数据库进程（可选，独立进程运行查询）                  │
└─────────────────────────────────────────────────────┘
        ↑ 受限 IPC
┌─────────────────────────────────────────────────────┐
│  插件进程（沙箱，按权限清单授权）                      │
└─────────────────────────────────────────────────────┘
        ↑ 受限 IPC
┌─────────────────────────────────────────────────────┐
│  远程服务进程（仅监听必要端口，可独立关闭）             │
└─────────────────────────────────────────────────────┘
```

| 原则 | 说明 |
|------|------|
| 崩溃隔离 | 插件崩溃、数据库崩溃不影响主程序 |
| 权限隔离 | UI 进程不能直接读写文件系统 |
| 资源隔离 | 每个进程有资源上限（CPU / 内存） |
| 可关闭 | 不需要的进程不启动（如未开启远程则不启动远程服务进程） |

### 7.3 常见漏洞防护

| 漏洞类型 | 防护措施 |
|---------|---------|
| **SQL 注入** | 全部参数化查询，禁止拼接 |
| **XSS** | 富文本渲染走白名单净化；禁止 `innerHTML` 拼接用户数据；CSP 严格策略 |
| **路径穿越** | 全部路径规范化后校验必须在允许目录内；拒绝 `..`、绝对路径、符号链接逃逸 |
| **任意文件读写** | 文件操作限定在数据目录与用户显式授权目录内 |
| **反序列化** | 不反序列化不可信结构；用严格 schema 校验 |
| **命令注入** | 不拼接 shell 命令；必须调用外部程序时使用参数数组形式 |
| **依赖漏洞** | 锁文件 + SCA 扫描 + 及时升级 |
| **供应链攻击** | 固定版本、校验哈希、可复现构建、SBOM |
| **原型污染**（JS 系） | 合并对象时拒绝 `__proto__` / `constructor` / `prototype` 键 |
| **本地端口劫持** | 远程服务绑定随机高位端口 + 强制鉴权，不信任来源 IP |
| **CSRF（本地服务）** | 校验自定义头与一次性 token，拒绝浏览器发起的跨域请求 |
| **时序攻击** | 敏感比较使用恒定时间比较 |
| **日志注入** | 日志中的换行符转义 |
| **剪贴板劫持** | 不自动执行剪贴板内容 |

### 7.4 富文本与外链安全

| 场景 | 策略 |
|------|------|
| Markdown 渲染 | 允许白名单标签；禁 `script` / `iframe` / `object` / `embed` / 内联事件 |
| 图片加载 | 远程图片默认**不加载**（显示占位），用户点击后才加载；可在设置中永久开启 |
| 链接点击 | 默认用系统浏览器打开；打开前显示完整 URL 让用户确认 |
| HTML 导出 | 导出时净化，不保留脚本 |
| 外链协议 | 仅允许 `http` `https` `mailto`；拒绝 `file:` / `javascript:` / 自定义协议 |

### 8.2 隐私说明页

用**通俗中文**（不是法律文档）解释：

| 问题 | 回答 |
|------|------|
| 我的数据存在哪？ | 在你的电脑上，具体路径见「我本机存了什么」 |
| 什么时候会联网？ | 只在你主动开启以下功能时：检查更新、下载 AI 模型、远程访问、同步、外部 AI。默认全部关闭 |

| 截图会上传吗？ | 不会。截图与 OCR 全部本地处理 |
| 卸载后会留下什么？ | 由你决定。可选择保留数据或彻底清除，清除时会列出所有将被删除的内容 |
| 你们收集使用统计吗？ | 不收集。我们没有服务器来收集 |
| 我怎么确认这些？ | 查看审计日志；用网络监视工具观察；审阅开源代码 |

## 九、安全开发生命周期

| 阶段 | 安全活动 |
|------|---------|
| **设计** | 威胁建模、隐私影响评估、数据分类、权限最小化评审 |
| **编码** | 安全编码规范、静态分析（SAST）、依赖扫描（SCA）、代码评审（安全改动需 2 人） |
| **构建** | 依赖锁定、SBOM 生成、可复现构建、无网络构建环境 |
| **测试** | 安全测试用例、模糊测试（用于解析器）、越权测试、注入测试、崩溃恢复测试 |
| **发布** | 代码签名、校验和、SBOM 发布、发布说明含安全变更 |
| **运维** | 漏洞响应流程（见 [SECURITY.md](../SECURITY.md)）、依赖升级、安全公告 |
| **下线** | 明确 EOL 日期，提供迁移路径，不静默停止支持 |

## 十、安全红线清单

以下为**不可协商**条款，任何 PR 违反即被拒绝：

| # | 红线 |
|---|------|
| 1 | 不引入遥测、埋点、崩溃上报、使用统计 |
| 2 | 不引入强制账号或强制登录 |
| 3 | 不在用户未开启网络时建立任何外部连接 |
| 4 | 不把用户数据发送到本机以外的任何地方（除非逐次显式授权） |
| 5 | 不使用字符串拼接构造 SQL |
| 6 | 不用 `innerHTML` 类 API 渲染用户数据 |
| 7 | 不把密钥、令牌、口令写入日志或错误信息 |
| 8 | 不降低已有加密强度 |
| 9 | 不扩大插件权限范围而不做公告 |
| 10 | 不把加密密钥放进备份包 |
| 11 | 不默认开启任何远程访问 |
| 12 | 不在未告知用户的情况下修改数据目录外的文件 |
| 13 | 不引入无网络隔离的第三方 SDK（分析、广告、社交） |
| 14 | 不在渲染进程直接暴露文件系统或数据库能力而不鉴权 |
| 15 | 不跳过发布前的签名与校验和环节（含紧急安全发布） |
