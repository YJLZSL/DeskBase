# 13 · 设置界面、教程系统与帮助系统详细设计

> 用户不该为了用一个功能而去看我们的文档。**帮助应该出现在他遇到问题的那一刻，而不是在另一个窗口里等他去找。**

## 一、设置系统

### 1.1 设计原则

| 原则 | 具体含义 |
|------|---------|
| **可搜索** | 搜"字体"能同时找到「外观」和「编辑器」两处的相关项 |
| **每项有解释** | 每个设置项旁有 `?`，点开说明：作用、默认值、取值范围、影响范围 |
| **有默认值可查** | 用户改错了能一键回退，也能看到"原来是什么" |
| **标注影响范围** | 标注该项影响哪些模块、是否涉及隐私、是否影响稳定性、是否需重启 |
| **可导入导出** | 整份设置可导出为 JSON / 可导入；支持选择性导出 |
| **可单项重置** | 每项右侧「恢复默认」 |
| **可全部重置** | 高级分类下提供，二次确认 |
| **高级默认折叠** | 折叠处标注「可能影响稳定性或隐私」 |
| **分类不超载** | 每个分类下的一级分组 ≤ 8 个 |

### 1.3 设置项信息模型

每个设置项在内部必须包含以下元数据（这也是「可搜索、有解释、可重置」能实现的基础）：

| 字段 | 说明 | 示例 |
|------|------|------|
| `key` | 唯一标识 | `appearance.theme` |
| `label` | 显示名称 | 主题 |
| `description` | 一句话说明 | 选择界面的配色方案 |
| `detail` | 详细解释（点 `?` 展开） | 宣纸为默认主题；可选 9 个内置主题或跟随系统；跟随系统会根据系统外观自动切换 |
| `default` | 默认值 | `xuan`（宣纸） |
| `type` | 类型 | enum / bool / number / string / path / list |
| `range` | 取值范围 | `["宣纸", "青瓷", "竹青", "朱墨", "夜墨", "松烟", "玄铁", "高对比（亮）", "高对比（暗）", "跟随系统"]` |
| `impact` | 影响范围 | `["全局界面"]` |
| `privacy` | 是否涉及隐私 | `false` |
| `stability` | 是否影响稳定性 | `false` |
| `needRestart` | 是否需重启 | `false` |
| `aliases` | 搜索别名 | `["配色", "颜色", "深色", "浅色", "theme"]` |
| `sinceVersion` | 引入版本 | `1.0.0` |

> **别名机制很重要**：用户搜"深色"应该能找到"主题"，搜"卡"应该能找到"性能"，搜"上传"应该能找到"网络访问"。

### 1.5 设置的导入导出

| 能力 | 说明 |
|------|------|
| 导出全部 | 生成 JSON，含所有设置 |
| 导出选择 | 可勾选只导出某些分类 |
| 脱敏导出 | 自动排除：数据目录路径中的用户名、服务地址、密钥相关项 |
| 导入 | 支持合并（只覆盖文件中出现的项）与替换（全部覆盖） |
| 冲突处理 | 导入前显示将变更的项列表，用户确认 |
| 危险项保护 | 导入不会开启网络相关项，需用户手动确认（除非导入时显式授权） |
| 版本兼容 | 旧版本设置文件导入时，不认识的项被忽略并提示 |

> **安全考量**：导入设置文件时，**不得因为文件里有 `remote.enabled: true` 就把远程访问打开**。涉及网络的设置必须由用户在界面上主动确认。这是防止"通过分享配置偷偷开启联网"的防线。

## 二、教程系统

### 2.1 设计原则

| 原则 | 说明 |
|------|------|
| **完全离线** | 不加载远程内容、不请求网络、不嵌入外部视频 |
| **可跳过、可重看** | 任何引导都能跳过；跳过的东西之后都能在帮助里找到 |
| **操作真实界面** | 交互式引导高亮真实控件，不用静态截图 |
| **示例数据可生成可清除** | 一键生成、一键彻底清除 |
| **不阻塞** | 引导以浮层方式呈现，用户可自由操作界面 |
| **失败容忍** | 用户没按引导做时，引导不报错、不卡住，允许"跳过这一步" |

### 2.2 新手引导（首启交互式）

```
第 1 步 · 欢迎
  「这是你的工作台。这里的每一份数据，都只存在你自己的电脑上。」
  → 高亮整个窗口

第 2 步 · 界面分区
  「左侧是十个功能模块，右上角搜索能找任何东西。」
  → 高亮侧边栏 + 搜索框

第 3 步 · 记第一条笔记
  「试着写下今天要做的一件事。」
  → 高亮"新建笔记"，打开编辑器，光标待输入
  → 用户输入后 → 「保存成功，它已经在你的电脑里了。」

第 4 步 · 建第一张表格
  「表格是它最常用的功能之一。」
  → 生成 3×3 示例表格，引导修改一个单元格
  → 引导点"排序"

第 5 步 · 截一次图
  「试试按 Ctrl+Shift+A，框选屏幕上任意一块。」
  → 真实触发截图（可跳过）

第 6 步 · 数据安全
  「你的数据在这里：D:\DeskBaseData」
  「自动备份已开启，每晚备份到本地。」
  → 高亮"备份状态"指示器

第 7 步 · 以后想再看？
  「随时在『帮助与教程』里找到这些内容。」
  → 完成

（全程：跳过 · 上一步 · 下一步；右上角可关闭整套引导）
```

| 空列表示例引导 | 显示"如何开始"的对应教程入口 |
| 首次进入某模块 | 一次性提示（可永久关闭），介绍该模块的核心动作 |

**帮助面板形态**：侧滑面板而非新窗口，避免用户"丢失上下文"。

## 三、帮助系统

### 3.1 结构

```
帮助与教程
├── 新手引导（可重看）
├── 场景教程（列表，可搜索）
├── 快捷键速查（可搜索、可就地修改）
├── SQL 入门（分级课程）
├── 备份与恢复教程
├── 远程连接教程
├── 隐私说明
├── 常见问题（FAQ，可搜索）
├── 上下文帮助索引
└── 反馈入口
    ├── 报告问题（跳转前提示勿含隐私）
    └── 提出建议
```

### 3.2 隐私说明页（通俗中文，不用法律语言）

```
隐私说明

数据存在哪？
  全部存在你自己的电脑上。具体位置见「设置 → 隐私与安全 → 我本机存了什么」。
  你随时可以复制、备份、删除它们。

什么时候会联网？
  只有在你主动开启以下功能后：
    · 检查更新
    · 下载本地 AI 模型
    · 手机远程访问
    · 自托管同步
    · 外部 AI 服务
  默认全部关闭。

会不会偷偷上传？
  不会。程序里没有遥测、没有埋点、没有崩溃上报。
  你可以拔掉网线使用全部核心功能，也可以自己抓包验证。
  程序内的审计日志会记录每一次网络连接的尝试。

AI 会看到我的数据吗？
  默认不会。AI 在你自己电脑上运行，推理过程不出网。
  如果你自己配置了外部 AI 服务，每次发送前都会给你看要发的内容。

截图会上传吗？
  不会。截图和 OCR 全部在你电脑上完成。

卸载后会留下什么？
  由你决定。
    · 保留数据卸载：只删程序，数据留着。
    · 彻底清除卸载：列清单 → 二次确认 → 全删。
  删除完成后会给你一份残留检查报告。

你们收集使用统计吗？
  不收集。我们没有这样的服务器。

我们做不到的事（诚实说明）
  · 如果你的电脑被他人物理接触，且对方知道你的口令，
    加密数据可能被读取。
  · 键盘记录器、屏幕录制等系统级威胁，我们无法防御。
  · 恶意插件（你主动安装的）可能造成风险。
  · 你自己导出后上传到别处，我们无法控制。
```

> **"我们做不到的事"这一节必须保留。** 诚实说明边界，比营造"绝对安全"的错觉更有价值。

### 3.3 FAQ 组织方式

按用户真实提问组织，而不是按功能模块：

| 分类 | 示例问题 |
|------|---------|
| 开始使用 | 我的数据存在哪？如何换电脑？如何卸载？ |
| 数据安全 | 备份真的能用吗？忘记密码怎么办？加密有必要吗？ |
| 常见困惑 | 为什么表格超过 X 万行变慢了？为什么不能连我的云盘？ |
| 截图 | 长截图截不好怎么办？截图存到哪了？ |
| 数据库 | 什么是索引？为什么要建关系？SQL 写错了怎么办？ |
| 性能 | 为什么占内存这么多？如何让它更省电？ |
| 隐私 | 怎么确认它没联网？如何彻底关闭 AI？ |
| 故障 | 崩溃了怎么办？断电后数据还在吗？打开库报错怎么办？ |

### 3.4 帮助内容规范

| 要求 | 说明 |
|------|------|
| 用中文写 | 不用翻译腔，不用"您可以…"这类生硬表达 |
| 先给答案 | 不铺垫，直接说怎么做 |
| 提供可操作步骤 | 具体到点哪个按钮 |
| 说明为什么 | 解释原因，用户才能迁移理解 |
| 承认限制 | 有做不到的就说明，不含糊 |
| 不用"敬请期待" | 不做的事情就说"不做" |
| 不写"请联系客服" | 没有客服，指向 GitHub Issues / Discussions |

## 四、帮助的可达性要求

| 要求 | 说明 |
|------|------|
| 全局可达 | `F1` 在任何界面都能唤起对应帮助 |
| 离线可读 | 全部帮助内容内置于程序中，不依赖网络 |
| 可搜索 | 帮助内容本身可被搜索（含正文） |
| 可复制 | 帮助文本可选中复制 |
| 不遮挡 | 帮助面板不遮挡当前操作区域（侧滑或可拖动） |
| 记住位置 | 再次打开帮助时回到上次阅读位置 |
| 打印/导出 | 帮助内容可导出为 Markdown 或打印 |

## 五、设置与帮助的质量验收

| # | 检查项 |
|---|-------|
| 1 | 每个设置项都有 `?` 说明，说明包含作用、默认值、取值范围、影响范围 |
| 2 | 每个设置项都能单项恢复默认 |
| 3 | 需要重启的设置项有明确标注 |
| 4 | 涉及隐私/稳定性的设置项有明确警告 |
| 5 | 搜索能通过别名找到设置项（如搜"深色"找到"主题"） |
| 6 | 设置可导出，导入时不会静默开启网络相关项 |
| 7 | 高级分类默认折叠并标注风险 |
| 8 | 全部教程离线可用（断网可完整走完） |
| 9 | 示例数据可一键生成、一键彻底清除 |
| 10 | 隐私说明包含"我们做不到的事" |
| 11 | `F1` 在任何页面都能给出对应帮助 |
| 12 | 帮助内容可搜索、可复制、可导出 |
| 13 | 无任何"请联系客服"或"敬请期待"表述 |
| 14 | 教程中无静态截图依赖（界面改版不会让教程失效） |
| 15 | 空列表均有引导文案 + 行动按钮 |
