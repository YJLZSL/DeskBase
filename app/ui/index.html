外观

11 个内置主题，分成四类。它们不只是换色 —— 圆角、描边、阴影语言、 字体、行距与密度都会一起变，所以切换时是整个界面气质的改变。
背景纸纹的明显程度。纸纹只在最底层，不覆盖文字与卡片内部，不消耗空闲 CPU。
动效服务于理解，不做循环播放的装饰动画。调到「关」会立刻停掉全部过渡与位移。
标题、模块名与大号数字所用的字体。内置的是「得意黑」（SIL OFL 1.1，1.10 MB，随程序分发，不联网下载）。
正文 / 代码 系统字体栈
正文走系统黑体（微软雅黑等），代码走系统等宽字体 —— 正文用字量最大， 内嵌中文字库得不偿失。自定义字体导入（.ttf / .otf / .woff2）尚未实现。

数据

导出为 Excel
按当前数据生成一个新的 .xlsx，**写到数据目录的 exports/ 下**，不会覆盖任何已有文件。 长编号（订单号、身份证）按文本写入，不会被 Excel 变成科学计数法。
导入表格
支持 .xlsx / .xlsm / .xls / .csv。**只读，不改你的文件。** 导入前会先检查那些会静默毁数据的坑（Excel 的 15 位精度截断、1904 日期系统、 HTML 伪装成 Excel、合并单元格），并把发现的问题逐条列出来。

格式转换

表格 / 图片 / 文本互转
支持 .xlsx ↔ .csv / .tsv、.png ↔ .jpg / .bmp / .webp， 以及 GBK / UTF-8 / UTF-16 之间的文本重编码。 只读原文件，结果永远写成新文件，已有文件一律不覆盖。

截图

屏幕截图
按物理像素抓取主显示器，存成 PNG 放到数据目录的 exports/ 下。 高 DPI 屏（125% / 150%）下会抓到完整分辨率，不是被拉伸过的模糊图。 截图内容只存在本机，不上传、不记录。

更新

当前版本 —
版本号形如 0.1.0-alpha.1。
默认关闭。开启后程序会向 api.github.com 请求一份发布清单 —— 只交换程序自己的版本与产物，不发送你的任何数据。每次出站（包括被跳过的尝试） 都会记进下面的审计日志。
稳定版不会把你带上 beta。测试版能看到更早的新功能，也更可能出问题。
检查与安装
三步各自要你点一次：检查 → 下载 → 替换。任何一步失败都不会改动现有程序。
已知限制
本程序没有代码签名证书，所以自己下载的更新无法验证发布者身份 —— 校验用的 SHA-256 与文件清单来自同一个 Release，账号一旦被攻破，这条链会一起失效。 换上来的新程序同样没有签名，运行时可能被 SmartScreen 拦。 想更稳妥就点上面的「打开发布页」手动下载，自己核对比对 .sha256 再覆盖。
审计日志 —
全部出站尝试都会记录（包括被拒绝的）。日志就在数据目录的 logs/ 下。
